# remove-chrome
A simple Bash script that uses Android Debug Bridge (ADB) to remove Google Chrome from an Android device for the primary user.

## Usage

- Install `adb` (Android Platform Tools).
- Enable USB debugging on your Android device. (Developer mod)
- Connect your phone via USB and authorize the connection.
- Run the script:

```bash
chmod +x remove-chrome.sh
./remove-chrome.sh
```
